We are excited to announce the initial release of **agentic-archive.is-ifier** – a Chrome extension for archiving URLs with [archive.is](https://archive.is) and similar services.

## What is agentic-archive.is-ifier?

agentic-archive.is-ifier is a browser extension that makes it easy to archive web pages and links directly from your browser context menu. Whether you want to preserve a page before it disappears or share a permanent snapshot of an article, this extension has you covered.

## Features in v1.2.0

- **Core archiving functionality** with support for archive.is services
- **Manifest v3 compliance** – built on the modern Chrome extension standards
- **Service worker** for efficient background processing
- **Context menu integration** – archive links, pages, and selected text with a right-click
- **Archive and copy** – archive a link and automatically copy the archive URL to your clipboard
- **Show archived versions** – quickly open the Wayback Machine for any URL
- **Extract real URLs** from archive.is/archive.ph links
- **Auto-archiving** – automatically archive pages containing specified text indicators
- **Pattern-based scanning** – configure URL patterns for targeted page scanning
- **Custom icon** – distinctive "is!" icon for easy identification in the toolbar
- **Comprehensive error handling** – notifications and error management throughout

## Installation

1. Clone or download the [repository](https://github.com/falkorichter/agentic-archive.is-ifier)
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extension directory

We welcome feedback and contributions via [GitHub Issues](https://github.com/falkorichter/agentic-archive.is-ifier/issues).
